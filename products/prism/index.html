미리보기

열지 않고, 바로 본다.

한글(HWP·HWPX)과 PDF를 각 프로그램을 열지 않고 탐색기 옆에서 쪽 그대로 봐요. 그림으로 된 스캔 PDF는 '글자 인식'을 누르면 이 PC 안에서 읽고 찾아요3.

Word·Excel·PowerPoint도 같은 자리에서 봐요2. 사진·카메라 RAW·PSD·SVG, 영상·소리, CSV 표, 글꼴, Markdown·코드·HTML도 같은 자리에서 봐요.

찾기

이름만 쳐도, 찾는다.

주소 칸의 돋보기(Ctrl+F)를 누르면 같은 칸이 '이 폴더에서 찾기'로 바뀌어요. *.zip, 보고서*처럼 *와 ?도 써요.

도구 칸의 '전체 파일 찾기'로는 PC 전체를 이름으로 찾아요. 사진·동영상·문서·압축 같은 종류 단추로 거르고, 시스템·임시 파일은 감춰 둬요.

영상 자르기

그 장면만, 짤로.

영상을 고르면 미리보기에서 바로 잘라요. 재생 막대 아래 구간 줄을 끌어 고르고, 'GIF 만들기'를 누르면 짤이 돼요. 화질은 상·중·하에서 골라요. GIF는 한 구간, 60초까지예요.

'구간 저장'은 고른 구간을 MP4 한 파일로, '구간 지우기'는 나머지를 한 파일로 만들어요. Ctrl+끌기로 여러 구간도 골라요. MP3·WAV 같은 소리 파일도 같은 방법으로 잘라요.

만든 파일은 원본 옆에 새 파일로 생기고, 원본은 그대로예요. 인터넷 없이 이 PC 안에서 만들고, 파일로 복사해 붙여 넣어요.

파일 작업

옮기고, 묶고, 되돌린다.

Windows 탐색기나 바탕화면의 파일도 끌어 놓을 수 있고, 놓은 자리에 들어가요. 같은 드라이브면 이동, 다른 드라이브면 복사예요.

압축하기는 묻지 않고 ZIP을 만들고 Ctrl+Z로 되돌려요. ZIP·tar도 풀어요. 복사·이동·휴지통 보내기 같은 큰 작업은 아래 작업 줄에서 돌아서, 그동안 창을 그대로 써요.

도구

작은 일은, 그 자리에서.

탐색기 줄 끝의 '도구와 더 보기' 단추로 도구 칸을 열어요. 메모장, 계산기(계산·단위·환율4·엑셀 탭, 계산 탭에는 공학용·프로그래머·날짜·그래프 모드), 레이어가 있는 그림판, 손그림5이 있어요.

글자 파일 두 개의 다른 곳을 보여 주는 '두 파일 비교', 고른 폴더에서 여는 터미널, 드라이브 남은 용량을 보는 '내 PC'도 같은 칸에 있어요. 메모는 파일로 저장해요(Ctrl+S).

그리고 더.

자주 쓰는 일을 조금씩 덜어 주는 것들이에요.

Markdown을 깔끔하게제목·코드 상자·표·체크 상자를 GitHub처럼 보여 줘요.
코드·설정 파일소스와 설정 파일을 미리 보고, 한글 ANSI(CP949) 파일도 읽어요.
어려운 ZIP도 목록부터한 번 누르면 안에 든 목록을 보고, 4GB까지의 ZIP과 tar·tar.gz도 풀어요.
다운로드는 받은 순서로다운로드 폴더는 오늘·어제·이번 주로 나눠 받은 순서대로 보여 줘요.
글자만 쳐도 그 파일로목록에서 글자를 치면 그 글자로 시작하는 파일·폴더로 바로 가요. 한글은 'ㄱ'만 쳐도 '기획안'을 찾아요.
폴더를 들여다보기왼쪽 칸 폴더 옆 작은 단추로, 그 폴더의 파일을 새것부터 바로 봐요.
네트워크 폴더도\\서버\공유 폴더를 쳐서 열고, 로그인은 Windows 창으로 해요.
OneDrive 파일도아직 내려받지 않은 OneDrive 파일은 OneDrive가 먼저 받은 뒤 보여 줘요.
숫자 순서 그대로1, 2, 10, 100처럼 숫자 이름을 숫자 순서로 정렬해요.
의견은 앱에서 바로도구와 더 보기 → 의견 보내기로 불편한 점을 바로 알려 줄 수 있어요.

설치와 업데이트

설치 파일은 SECOND SYNTAX가 직접 만들어 GitHub(second-syntax/prism-download)에 올려요. 관리자 승인 없이 내 계정에만 설치하고, Windows 설정 → 앱에서 지워요.

새 버전이 나오면 알려 드려요. 알림에서 '업데이트'를 누르면 새 설치 파일을 받아 확인한 뒤, '다시 시작해서 적용'을 누를 때 설치하고 Prism을 다시 켜요. 누르지 않으면 아무것도 받지 않아요.

알림에서 누르는 업데이트는 0.1.2를 설치한 뒤 나오는 다음 버전부터 쓸 수 있어요. 0.1.1에서 0.1.2로는 이 페이지에서 새 설치 파일을 받아 실행해 주세요.

의견 보내기

도구 메뉴의 '의견 보내기'에서 불편한 점이나 바라는 점을 바로 보낼 수 있어요. '보내기'를 눌러야만 가요.

쓴 글과 함께 프로그램 정보(팩·버전·Windows 빌드·화면 배율·표시 언어)가 가는데, 보내기 전에 그대로 보여 드리고 끌 수 있어요. 답을 받을 메일은 넣고 싶을 때만 넣으면 돼요. 받은 의견은 1년 뒤 지워요.

Prism이 인터넷을 쓰는 때내가 누르거나 연 것 때문에 필요할 때만 인터넷을 써요.

인터넷을 쓰는 때

  • 계산기 환율 탭을 열 때: 환율을 받아요4
  • OneDrive 같은 클라우드 파일을 열 때: 그 서비스가 파일을 내려받아요
  • 하루 한 번 새 버전 확인: GitHub에서 릴리스 목록을 읽어요(끌 수 있어요)
  • 알림에서 '업데이트'를 누를 때: GitHub에서 새 설치 파일을 받아요
  • '의견 보내기'에서 '보내기'를 누를 때: 쓴 의견을 SECOND SYNTAX가 쓰는 Cloudflare로 보내요
  • HTML·한글 미리보기를 열 때: 미리보기를 그리는 Microsoft Edge WebView2 엔진이 Microsoft Edge 설정 서버에서 설정을 받아요(엔진·Windows 버전과 기기 식별 번호가 가요)

Lite 팩 권장

필요한 것만 남긴 탐색기예요. 탐색기 창 하나와 폴더 트리, 미리보기, 이름 찾기, 기본 파일 작업, 메모장·계산기·그림판·손그림 같은 도구.

𝗟𝗶𝘁𝗲 팩 내려받기
필요한 것
운영체제Windows 11 64비트(x64). Windows 10은 시험을 마친 뒤 알려 드릴게요.
설치 공간약 340MB예요. 내려받는 설치 파일은 약 100MB예요.
따로 설치할 것없어요. 글자 인식에 쓰는 Microsoft Visual C++ 런타임이 없는 PC라면 설치 화면이 Microsoft에서 받아 설치해요(관리자 승인 한 번).
인터넷설치 파일을 받을 때, 업데이트할 때, 의견을 보낼 때, 환율 탭을 열 때, 클라우드 파일을 열 때만 필요해요.
설치할 때 경고 창아직 코드 서명 전이라 'Windows의 PC 보호' 창이 뜰 수 있어요. '추가 정보 → 실행'을 누르면 설치돼요. 스마트 앱 컨트롤이 켜진 PC에서는 아직 설치할 수 없어요.

자주 묻는 질문

AI 기능이 있나요?

Lite 팩에는 AI 기능이 없어요. 탐색·미리보기·찾기·파일 작업·도구는 모두 AI 없이 이 PC 안에서 동작해요.

내 파일 내용이 밖으로 나가나요?

아니요. Prism은 파일 내용이나 이름, 경로를 밖으로 보내지 않아요. 인터넷은 환율 탭이나 OneDrive 같은 클라우드 파일을 열 때, 새 버전을 확인하고 업데이트할 때, 내가 의견을 보낼 때만 써요.

도구 단추가 안 보여요.

Lite 팩은 화면을 단순하게 두려고 단추를 하나로 모았어요. 탐색기 줄 오른쪽 끝 '도구와 더 보기'를 한 번 누르면 도구 칸이 열리고, 열린 뒤에 누르면 미리보기·새 폴더·정렬·보기·테마 메뉴가 떠요.

잘라내기·복사·붙여넣기·이름 바꾸기·지우기는 오른쪽 클릭 메뉴와 단축키로 해요.

Word·PowerPoint 파일은 어떻게 보이나요?

이 PC에 Microsoft Office가 있으면 Office의 미리보기로 서식 그대로 보여 줘요. 없으면 Word·PowerPoint는 본문 글자를, Excel은 표를 보여 줘요. DOC·XLS·PPT 같은 옛 형식은 파일 정보만 보여 줘요.

설치할 때 경고 창이 떠요.

아직 코드 서명 인증서가 없는 새 프로그램이라 'Windows의 PC 보호' 창이 뜰 수 있어요. '추가 정보 → 실행'을 누르면 설치돼요.

스마트 앱 컨트롤이 켜진 PC에서는 서명 없는 프로그램이 실행되지 않아서 아직 Prism을 쓸 수 없어요. 받은 파일이 원본과 같은지는 내려받기 페이지의 SHA-256 값으로 확인할 수 있어요.

회사 PC에서도 되나요?

회사 보안 정책 때문에 설치가 막힐 수 있어요. 개인 PC에서 써 보시고, 회사 PC는 관리자에게 먼저 물어보세요.

한글 파일을 고칠 수도 있나요?

Prism의 한글·Office 미리보기는 보기 전용이에요. 고칠 때는 한글이나 Office 프로그램에서 열어 주세요.

지금 쓰는 Windows 탐색기는 어떻게 되나요?

그대로 있어요. Prism은 따로 설치하는 앱이라 Windows 탐색기와 함께 쓸 수 있어요.

업데이트는 어떻게 받나요?

새 버전이 나오면 Prism이 알려 줘요. 알림에서 '업데이트'를 누르고, 다 받으면 '다시 시작해서 적용'을 누르세요. 설정과 기록은 남아요. 누르지 않으면 아무것도 받지 않아요.

0.1.1을 쓰고 있다면 이 페이지에서 새 설치 파일을 받아 실행해 주세요. 알림에서 누르는 업데이트는 0.1.2 다음 버전부터예요.

의견이나 버그는 어디로 보내나요?

Prism의 도구 메뉴에서 '의견 보내기'를 누르면 바로 보낼 수 있어요. 메일로 보내셔도 돼요: secondsyntax.official@gmail.com

보내 주신 의견과 메일은 답장과 문제 해결에만 써요. 무엇이 가고 얼마나 보관하는지는 개인정보처리방침에 있어요.

𝗟𝗶𝘁𝗲 팩 내려받기
  1. 화면은 Lite 팩 0.1.2와 같은 화면의 시험 빌드에서, 시험용으로 만든 폴더와 그림을 써 보며 찍은 것이에요.
  2. Word·Excel·PowerPoint는 이 PC에 설치된 Microsoft Office의 미리보기로 서식 그대로 보여 줘요. Office가 없으면 Word·PowerPoint는 본문 글자를, Excel은 표를 보여 줘요. 인터넷에서 받은 Office 파일은 Windows가 미리보기를 막아서 안내만 보여 줘요. DOC·XLS·PPT 같은 옛 형식은 파일 정보만 보여 줘요.
  3. 글자 인식은 PP-OCRv5로 이 PC 안에서 동작하고, 한국어와 영어를 읽어요.
  4. 환율 탭을 열 때 받아 둔 환율이 없거나 1시간이 지났으면, 유럽중앙은행(ECB) 기준환율을 인터넷에서 받아요. 수수료는 들어 있지 않아요.
  5. 손그림은 오픈 소스 Excalidraw를 바탕으로 만들었고, 인터넷을 쓰지 않아요.
  6. 한글은 한글과컴퓨터의, Windows·Word·PowerPoint·Excel·OneDrive는 Microsoft의, GitHub는 GitHub, Inc.의 상표예요.
