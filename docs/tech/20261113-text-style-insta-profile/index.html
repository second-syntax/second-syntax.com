SECOND SYNTAX가 직접 만든 무료 도구로 설명하는 글이에요. 제휴 링크는 없어요. 캐릭터 PAGE 그림은 AI 이미지 생성이에요.

인스타 프로필 글씨체 바꾸는 법, 한글 이름과 소개글까지

인스타 프로필을 보다 보면 이름이 𝗱𝗮𝗶𝗹𝘆 𝗰𝗼𝗳𝗳𝗲𝗲 처럼 굵거나, 𝓭𝓪𝓲𝓵𝔂 𝓬𝓸𝓯𝓯𝓮𝓮 처럼 필기체인 계정이 있어요. 인스타에 글씨체 설정이 따로 있는 게 아니에요. 생김새가 다른 글자(유니코드 글자)를 붙여 넣은 거예요.

방법은 세 단계예요. 글씨 뚝딱에 쓰고, 마음에 드는 칸을 누르고, 인스타 프로필 편집에 붙여 넣어요. 영문은 22가지 글씨체로, 한글은 ㅅr랑ㅎH 같은 외계어로 바꿀 수 있어요. 앱을 깔거나 로그인할 필요가 없어요.

1단계: 글씨 뚝딱에 이름이나 소개글 쓰기

폰 브라우저에서 second-syntax.com/text-style 을 열고 칸에 프로필에 넣을 말을 써요. 영문을 쓰면 글씨체 15칸이 한꺼번에 나와요. ‘다시 추천’을 누르면 다른 조합이 나오고, 글씨체는 모두 22가지예요.

  • 깔끔한 굵게: 𝗱𝗮𝗶𝗹𝘆 𝗰𝗼𝗳𝗳𝗲𝗲
  • 굵은 필기체: 𝓭𝓪𝓲𝓵𝔂 𝓬𝓸𝓯𝓯𝓮𝓮
  • 타자기: 𝚍𝚊𝚒𝚕𝚢 𝚌𝚘𝚏𝚏𝚎𝚎

2단계: 마음에 드는 칸 누르기

칸을 누르면 그 글씨가 복사돼요. 긴 소개글도 전체가 복사돼요.

3단계: 인스타 프로필 편집에 붙여 넣기

  1. 인스타 앱에서 내 프로필 → 프로필 편집을 눌러요.
  2. 이름 또는 소개 칸을 눌러 원래 글을 지우고, 길게 눌러 붙여넣기를 해요.
  3. 오른쪽 위 완료(✓)를 눌러 저장해요.

갤럭시 Z 폴드8에서 해 보니 이름 칸에 넣은 굵은 기울임 글씨와 소개 칸에 넣은 ㅅr랑ㅎH가 프로필 편집 화면에 그대로 보였어요. SECOND SYNTAX 인스타(@second.syntax) 이름도 이 방법으로 굵은 글씨로 바꿔 저장했어요.

한글 이름과 소개글은 외계어로

굵은 글씨나 필기체 같은 유니코드 글씨체는 한글에는 없어요. 그래서 한글을 쓰면 글씨 뚝딱이 한글 탭으로 바꿔서, 자음·모음을 생김새가 닮은 외국 글자와 기호로 바꿔 줘요.

  • 미니홈피 감성: 사랑해 → ㅅr랑ㅎH
  • 한자·영어 장난: 있어要 · 오늘道 · 火이팅 · GO마워

한글 글씨는 15가지이고, 바뀌는 말이 있으면 한자·이모지·영어 장난 칸 3가지가 더 나와요. 소개글 한 줄만 외계어로 바꿔도 분위기가 달라져요.

알아 둘 것

  • 사용자 이름(@아이디)에는 못 써요. 인스타 사용자 이름은 영문·숫자·마침표·밑줄만 받아요. 꾸민 글씨는 이름과 소개 칸에 써요.

  • 이름은 14일 동안 두 번까지만 바꿀 수 있어요. 인스타 이름 편집 화면에 나오는 안내예요(2026년 11월 확인). 먼저 소개 칸에서 여러 글씨체를 써 보고, 마음에 드는 걸 이름에 넣는 편이 좋아요. 소개는 150자까지 쓸 수 있어요.

  • 인스타 소개 칸에도 자체 ‘글꼴 변경’ 단추가 있어요. 그 단추에 없는 글씨체나 한글 외계어가 필요할 때, 그리고 같은 글씨를 카톡·닉네임에도 쓰고 싶을 때 글씨 뚝딱이 편해요.

  • 보는 사람 폰에 따라 다르게 보일 수 있어요. 아이폰은 아직 직접 확인하지 못했어요. 기기나 앱 글꼴에 따라 몇몇 글자가 네모(□)로 보일 수 있어요.

  • 이름 전체보다 한두 낱말에만 쓰는 편이 좋아요. 화면을 읽어 주는 기능(스크린 리더)은 꾸민 글자를 제대로 읽지 못할 수 있어요.

  • 숫자는 일부 글씨체에서만 바뀌어요.

쓴 글은 어디로 가나요

쓴 글은 서버로 보내지 않아요. 글씨를 바꾸는 일은 페이지 안에서 끝나요. 어떤 글씨체가 많이 쓰이는지 보려고 복사한 횟수만 글씨체별로 세요.
