SECOND SYNTAX가 직접 만든 무료 도구를 소개하는 글이에요. 제휴 링크는 없어요. 캐릭터 PAGE 그림은 AI 이미지 생성이에요.

키보드로 못 치는 글씨를 메신저에, 한글도 되는 글씨 뚝딱을 만들었어요

카톡이나 인스타에서 굵은 글씨나 필기체 같은 꾸민 글씨를 본 적 있죠. 이런 글씨는 폰 키보드로는 칠 수 없어요. 우리가 주로 쓰는 한글은 더 그래요.

그래서 SECOND SYNTAX가 키보드에 없는 글씨를 메신저와 프로필에 쓰게 해 주는 무료 웹 도구 ‘글씨 뚝딱’을 만들었어요. 하고 싶은 말을 쓰면 영문은 22가지 유니코드 글씨체로, 한글은 외계어로 바꿔 줘요. 마음에 드는 칸을 눌러 카톡·인스타에 붙여 넣으면 끝이에요. 설치도 로그인도 없어요.

👉 https://second-syntax.com/text-style/

한눈에

무엇키보드로 못 치는 꾸민 글씨를 메신저·프로필에 쓰게 해 주는 도구
어디서second-syntax.com/text-style/ (폰·PC 브라우저)
값무료, 설치·로그인 없음
영문유니코드 글씨체 22가지(깔끔한 굵게·부드러운 필기체·두 줄 아웃라인·타자기 등). 한 번에 15칸을 보여 줘요
한글외계어 15가지와 한자·이모지·영어 장난 3가지. 생일 축하처럼 아는 말은 통째로 바꿔 줘요
AI 추천원할 때만 켜는 분위기 추천. 페이지 안에서 돌고, 글은 밖으로 나가지 않아요

쓰는 법: 쓰고, 고르고, 메신저에 붙이기

  1. 쓰기. 칸에 영문이나 한글을 써요. 한글만 쓰면 한글 탭으로 저절로 바뀌어요.
  2. 고르기. 첫 줄 3칸은 기본 추천이고, 영문은 글 분위기에 맞춰 바뀌기도 해요. 15칸 가운데 마음에 드는 걸 골라요. ‘다시 추천’을 누르면 다른 조합이 나와요.
  3. 붙이기. 칸을 누르면 복사돼요. 카톡 대화나 인스타 소개글·닉네임·댓글에 붙여 넣으면 끝이에요. 긴 문구도 전체가 복사돼요.

한글은 외계어로

한글을 쓰면 자음·모음을 생김새가 닮은 외국 글자(라틴 문자·가나·한자·기호)로 바꿔 써 줘요. ㅅr랑ㅎH처럼 미니홈피 시절에 쓰던 말투도 있어요.

한두 글자만 소리가 같은 한자나 영어로 바꾸는 장난도 있어요. 있어要, 오늘道, 火이팅, GO마워 같은 식이에요. 아는 말은 이모지(🎂)나 영어 소리(saranghae)로도 적어 줘요. 생일 축하해를 쓰면 생日 축하海와 🎂가 나오고, 언니 생일 축하해처럼 부르는 말을 붙이면 언니 HBD로 줄여 줘요.

분위기 추천 AI는 내 기기 안에서

✨ AI 추천을 켜면 페이지 안에 든 작은 분위기 모델(약 0.9MB)이 글 분위기에 맞는 글씨체를 골라 줘요. 이 모델은 브라우저 안에서 돌기 때문에 쓴 글은 서버로 나가지 않아요. 한글 글은 아는 낱말을 영어 낱말로 바꾼 뒤 같은 모델이 읽어요. 모델은 공개 모델 potion-retrieval-32M(MIT 라이선스)을 바탕으로 직접 학습했어요.

학습 때 보지 않은 시험 문장으로 재 보니, 영어는 128문장 가운데 101문장, 한글은 180문장 가운데 134문장(74%)에서 분위기를 맞혔어요. 늘 맞히지는 않아요. 추천이 마음에 안 들면 ‘다시 추천’을 누르거나 15칸에서 직접 고르면 돼요.

어떤 글씨체가 많이 쓰이는지 보려고 복사한 횟수를 세요. 이때 보내는 건 고른 글씨체, 한글·영문 구분, AI 추천 칸인지 세 가지뿐이고, 쓴 글은 보내지 않아요. 너무 많이 눌리는 걸 막으려고 접속 주소(IP)는 원래 값 대신 되돌릴 수 없게 바꾼 값으로만 이틀쯤 두고 지워요.

붙여 넣기 전에 알아 둘 것

  • 갤럭시 Z 폴드8에서 확인해 보니 크롬의 영문·한글 칸이 모두 제대로 보였고, 인스타 프로필 편집의 이름·소개 칸과 카톡 대화에 붙여 넣어도 그대로 보였어요. 카톡으로 보낸 글씨는 받은 사람 폰에서도 같은 모양이었어요.
  • 아이폰은 아직 직접 확인하지 못했어요. 받는 사람의 기기나 앱 글꼴에 따라 몇몇 글자가 네모(□)나 다른 모양으로 보일 수 있어요.
  • 화면을 읽어 주는 기능(스크린 리더)은 꾸민 글자를 제대로 읽지 못할 수 있어요. 이름 전체보다 한두 낱말에만 쓰는 편이 좋아요.
  • 숫자는 일부 글씨체에서만 바뀌어요.

친구에게 보내기

페이지의 ‘공유’ 단추를 누르면 폰의 공유 창이 열려요. 공유 창이 없는 브라우저에서는 링크가 복사돼요. 카톡에 링크를 보내면 미리보기 그림과 소개가 함께 떠요.
