Prism Lite 팩 공개, 한글·PDF를 열지 않고 보고 이름만 쳐도 찾는 Windows 탐색기

한글 파일 하나 확인하려고 한글 프로그램을 열고, 닫고, 다음 파일을 또 여는 일이 많지 않나요? 파일 이름이 정확히 기억나지 않아 폴더를 이리저리 뒤지는 일도요.

Prism은 파일을 열지 않고 탐색기에서 바로 보고, 이름 몇 글자만 쳐도 드라이브 전체에서 찾아 주는 Windows 탐색기예요. 필요한 것만 남긴 Lite 팩을 SECOND SYNTAX 사이트에서 내려받을 수 있게 공개했어요.

👉 https://second-syntax.com/products/prism/ 의 ‘Lite 팩 내려받기’ 단추

① 열지 않고, 바로 본다

파일을 고르면 탐색기 오른쪽에 바로 보여요.

  • 한글(HWP·HWPX)과 PDF는 쪽 그대로 봐요. PDF는 글자를 골라 복사할 수 있어요.
  • Word·Excel·PowerPoint는 이 PC에 설치된 Microsoft Office의 미리보기로 보여 줘요.
  • 사진과 글 파일도 같은 자리에서 봐요.

미리보기는 보기 전용이에요. 고칠 때는 한글이나 Office 프로그램에서 열어 주세요.

② 이름만 쳐도, 찾는다

드라이브 전체 파일을 이름으로 찾아요. 입력하는 대로 목록을 걸러 내서, 이름이 반만 기억나도 찾을 수 있어요. 지금 보는 폴더 안에서만 찾을 수도 있어요.

③ 작은 일은, 탐색기 옆에서

메모장·계산기·그림판이 탐색기 옆 도구함에 있어요. 다른 프로그램을 따로 띄우지 않고 그 자리에서 써요.

  • 메모장: 메모 한 장을 쓰고, 남기고 싶으면 파일로 저장해요.
  • 계산기: 단위와 환율도 바꿔 봐요. 환율은 환율 탭을 열 때 인터넷에서 받아요.
  • 그림판: 간단히 그리고 그림 파일로 저장해요.

그 밖에 손그림, 내 PC 용량, 두 파일 비교, 터미널, 선택한 파일 인쇄도 같은 도구 줄에 있어요.

④ 필요한 것만 남긴 화면

Lite 팩은 탐색기 창 하나와 왼쪽 폴더 트리로 이루어진 가벼운 화면이에요. 탐색기 줄 끝의 ‘도구와 더 보기’ 단추 하나로 도구 칸을 열고, 미리보기·새 폴더·정렬·보기·테마 메뉴도 거기서 열어요.

복사·잘라내기·붙여넣기·이름 바꾸기·휴지통은 Windows 탐색기에서 쓰던 단축키와 오른쪽 클릭 메뉴 그대로예요. 방금 한 파일 작업은 Ctrl+Z로 되돌릴 수 있어요.

지금 쓰는 Windows 탐색기는 그대로 있어요. Prism은 따로 설치하는 앱이라 함께 쓸 수 있어요.

파일은 이 PC 안에서

탐색·미리보기·찾기·파일 작업·도구는 모두 이 PC 안에서 동작해요. Prism은 파일 내용이나 이름, 경로를 밖으로 보내지 않아요. 계정을 만들거나 로그인할 일도 없어요. Lite 팩에는 AI 기능이 없어요.

Prism이 인터넷을 쓰는 때는 아래와 같아요. 0.1.2 설치본을 재어 보니, 아무것도 누르지 않은 동안 Prism 자신은 새 버전 확인 1건(GitHub)만 연결했어요.

  • 계산기의 환율 탭을 열 때 환율을 받아요.
  • OneDrive 같은 클라우드 파일을 열 때 그 서비스가 파일을 내려받아요.
  • 새 버전이 나왔는지 하루 한 번 확인해요. 이때 가는 것은 요청 자체뿐이고, 파일·경로·설정은 보내지 않아요.
  • 알림에서 ‘업데이트’를 누르면 GitHub에서 새 설치 파일을 받아요. 누르지 않으면 받지 않아요.
  • ‘의견 보내기’에서 ‘보내기’를 누르면 쓴 의견을 SECOND SYNTAX가 쓰는 Cloudflare로 보내요. 보내기 전에 함께 가는 프로그램 정보(팩·버전·Windows 빌드·화면 배율·표시 언어)를 그대로 보여 주고, 끌 수 있어요. 받은 의견은 1년 뒤 지워요.
  • HTML·한글 미리보기를 그리는 Windows의 Microsoft Edge WebView2 엔진이 켜질 때 Microsoft의 설정 서버에서 설정을 받아요. 파일 이름·내용·경로는 가지 않아요.

자세한 내용은 개인정보처리방침에 있어요: https://second-syntax.com/products/prism/privacy/

내려받기와 설치

  1. 소개 페이지(https://second-syntax.com/products/prism/)에서 Lite 팩 설치 파일 Prism-Lite-Setup-0.1.2.exe를 받아요.
  2. 받은 파일을 실행해요. 경고 창이 뜨면 아래 안내를 읽어 주세요.
  3. 설치가 끝나면 시작 메뉴의 ‘Prism Lite 팩’으로 열어요.

설치할 때 뜨는 경고 창

  • 내려받은 설치 파일을 열면 “Windows의 PC 보호” 창이 뜰 수 있어요. 아직 코드 서명 인증서가 없는 새 프로그램이라서 그래요. “추가 정보 → 실행”을 누르면 설치돼요.

  • 스마트 앱 컨트롤이 켜진 PC에서는 서명 없는 프로그램이 실행되지 않고, 넘기는 버튼이 없어요. 이런 PC에서는 아직 Prism을 쓸 수 없어요.
  • 회사 PC는 보안 정책 때문에 설치가 막힐 수 있어요. 개인 PC에서 써 보세요.
  • 설치는 관리자 승인 없이 내 계정에만 해요. 지울 때는 Windows 설정 → 앱에서 지워요.

받은 파일이 원본과 같은지는 내려받기 페이지에 적힌 SHA-256 값으로 확인할 수 있어요.

설치 조건

  • Windows 11 64비트(x64)
  • 설치 파일은 약 100MB, 설치하면 약 340MB를 차지해요.
  • 글자 인식에 쓰는 Microsoft Visual C++ 런타임이 없는 PC에서는, 설치 화면이 Microsoft에서 받아 설치하도록 안내해요(관리자 승인 한 번).

업데이트

  • Prism은 하루 한 번 새 버전이 나왔는지 확인하고, 나왔으면 “새 버전이 나왔어요” 알림을 띄워요.
  • 알림에서 ‘업데이트’를 누르면 새 버전을 받아요. 받는 동안에도 창은 그대로 쓸 수 있어요. 받은 파일은 SECOND SYNTAX가 서명한 목록과 맞는지 확인한 뒤에만 써요. ‘다시 시작해서 적용’을 누르면 설치하고 Prism을 다시 켜요.
  • 누르지 않으면 아무것도 받지 않아요. 알림은 ‘도구와 더 보기’ 메뉴의 ‘업데이트 알림 받기’로 끌 수 있어요.
  • 이렇게 누르는 업데이트는 이번 버전 다음에 나오는 버전부터 쓸 수 있어요. 예전 버전(0.1.1)을 쓰고 계셨다면 이번에는 소개 페이지에서 새 설치 파일을 받아 실행해 주세요. 설정과 기록은 남아요.
