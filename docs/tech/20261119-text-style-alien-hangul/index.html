SECOND SYNTAX가 직접 만든 무료 도구로 설명하는 글이에요. 제휴 링크는 없어요. 캐릭터 PAGE 그림은 AI 이미지 생성이에요.

한글 외계어 만드는 법, 미니홈피 감성 ㅅr랑ㅎH부터 15가지

미니홈피 대문에 ㅅr랑ㅎH라고 적던 때가 있었죠. 한글 자음·모음을 생김새가 닮은 영어 글자나 기호로 바꿔 쓰는 말투라서 외계어라고 불러요. 손으로 하나씩 바꾸려면 특수문자를 일일이 찾아야 해서 번거로워요.

글씨 뚝딱에 한글을 쓰면 꾸민 글씨 15칸이 한꺼번에 나와요. 마음에 드는 칸을 누르면 복사되고, 메신저나 프로필에 붙여 넣으면 끝이에요. 앱을 깔거나 로그인할 필요가 없어요.

👉 https://second-syntax.com/text-style/

쓰는 법: 쓰고, 고르고, 붙이기

  1. 쓰기. 폰 브라우저에서 second-syntax.com/text-style 을 열고 한글을 써요. 한글만 쓰면 한글 탭으로 저절로 바뀌어요.
  2. 고르기. 첫 줄 3칸은 미니홈피 감성·외계어 정석·섞어 쓰기예요. 아래 칸까지 15칸 가운데 마음에 드는 걸 골라요. ‘다시 추천’을 누르면 아래 칸이 다른 글씨로 바뀌어요.
  3. 붙이기. 칸을 누르면 복사돼요. 메신저 대화나 프로필 소개에 붙여 넣어요.

외계어는 이렇게 만들어져요

글자를 자음·모음으로 풀고, 닮은 글자가 있는 낱자만 바꿔요. 예를 들면 ㅏ는 r, ㅐ는 H, ㅇ은 O, ㄴ은 L과 닮았어요.

  • 사 = ㅅ + ㅏ → ㅅr
  • 해 = ㅎ + ㅐ → ㅎH

‘미니홈피 감성’은 받침 없는 글자의 모음만 바꿔요. 그래서 받침이 있는 ‘랑’은 그대로 두고 사랑해가 ㅅr랑ㅎH가 돼요. 한글이 많이 남아서 읽기 쉬워요. ‘외계어 정석’은 받침 있는 글자까지 풀어 ㅅr ㄹrO ㅎH처럼 써요.

바꾼 글자는 그림이 아니라 진짜 글자예요. 그래서 복사해 붙여 넣어도 모양이 그대로예요.

섞어 쓰기·반쯤 외계어·미니홈피 섞어·먼 나라 섞기·이모지 동그라미는 닮은 글자 여러 개 가운데 하나를 골라 써요. ‘다시 추천’을 누르면 이 칸들의 글자가 바뀌어요. 위 표는 그중 한 가지 모습이에요.

화면에는 한 번에 15칸이 나와요. 첫 줄 3칸은 늘 같고, 나머지 칸은 위 15가지와 곰 글씨 2가지 가운데에서 골라 채워요. 표에는 있는데 화면에 안 보이는 글씨는 ‘다시 추천’을 누르면 나와요.

곰 글씨는 11월에 더했어요. ‘곰 귀’는 사랑해를 ʕ사ʔʕ랑ʔʕ해ʔ처럼 글자마다 귀를 달고, ‘곰 떼’는 글 양옆에 기호로 그린 곰 얼굴을 세 마리씩 세워요.

골라 쓰는 요령

  • 읽히길 바라면 미니홈피 감성이나 반쯤 외계어를 써요. 한글이 많이 남아요.
  • 암호처럼 보이길 바라면 수식 외계어나 먼 나라 섞기를 써요. 한글이 거의 남지 않아요.
  • 귀엽게 쓰려면 동그라미 한글(가나다라 → ㉮ ㉯ ㉰ ㉱)이나 이모지 동그라미가 있어요.
  • 영어 소리는 한글을 소리 나는 대로 영어 글자로 적어요. 감사합니다는 gamsahamnida, ㅠㅠ는 TT가 돼요.

보라 칸: 한자·이모지·영어 장난

바뀌는 말이 있으면 보라색 칸이 따로 나와요. 한두 글자만 소리가 같은 한자나 영어로 바꾸는 장난이에요.

쓴 말한자 장난이모지로 말하기영어 장난
사랑해사랑海❤️(바뀌는 말이 없어 안 나와요)

오늘도 화이팅오늘道 火이팅📅 💪오늘도 FIGHTING

보라 칸도 ‘다시 추천’을 누르면 바뀌는 자리가 달라질 수 있어요.

어디에 쓰나요

  • 인스타 프로필 소개. 갤럭시 Z 폴드8에서 소개 칸에 ㅅr랑ㅎH를 붙여 넣어 보니 그대로 보였어요. 자세한 순서는 인스타 프로필 글씨체 바꾸는 법에 있어요.
  • 메신저 대화와 상태 메시지, 게임·커뮤니티 닉네임. 닉네임은 서비스마다 받는 글자가 달라요. 안 들어가면 미니홈피 감성이나 숫자 암호처럼 영어 글자·숫자만 섞는 칸을 써 보세요.

알아 둘 것

  • 보는 사람 폰에 따라 다르게 보일 수 있어요. 갤럭시 Z 폴드8 크롬에서는 외계어 15가지가 모두 네모 없이 보였어요. 아이폰은 아직 직접 확인하지 못했어요. 수식 외계어·먼 나라 섞기·곰 떼처럼 드문 글자를 쓰는 칸은 보내기 전에 나에게 먼저 보내 확인해 보세요.
  • 외계어로 쓴 말은 검색에 안 잡혀요. 글자가 달라서 그래요. 남이 찾아야 하는 이름이나 가게 이름에는 쓰지 않는 편이 좋아요.
  • 화면을 읽어 주는 기능(스크린 리더)은 외계어를 제대로 읽지 못할 수 있어요. 긴 글 전체보다 한두 낱말에만 쓰는 편이 좋아요.

쓴 글은 어디로 가나요

쓴 글은 서버로 보내지 않아요. 글씨를 바꾸는 일은 페이지 안에서 끝나요. 어떤 글씨체가 많이 쓰이는지 보려고 복사한 횟수를 글씨체별로 세고, 방문 수는 쿠키 없이 세요.
