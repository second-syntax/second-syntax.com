앤트로픽 공식 글(11월 23일)과 테크크런치·더버지 보도를 대조해 정리한 글이에요. 제휴 링크는 없어요. 4컷 만화의 장면 그림과 캐릭터는 AI 이미지 생성이고, 말풍선 글자는 직접 넣었어요.

앤트로픽 클로드 십 출시, AI가 코드 검사·통과까지 맡아도 될까

클로드 십 — AI가 코드 검사, 고치고 통과까지 맡겨도 될까? (캐릭터는 AI 이미지 생성)

반 친구가 숙제를 하루에 백 장씩 써 온다고 해 볼게요. 숙제를 쓰는 속도는 엄청 빨라졌는데, 검사하는 선생님은 한 명 그대로예요. 결국 숙제는 선생님 책상 위에 산처럼 쌓이죠.

앤트로픽이 11월 23일, AI가 쓴 코드를 검사하고, 틀린 곳을 고치고, 팀 규칙에 맞으면 통과 판단까지 해 주는 ‘클로드 십(Claude Ship)‘을 내놨어요. 지금은 팀·엔터프라이즈 요금제에서 깃허브(코드 보관소)에 둔 프로젝트에 쓸 수 있어요.

4컷 만화 — 숙제를 빨리 쓰는 AI 옆에서 검사하는 사람만 바빴는데, 이제 AI가 검사·고치기·통과 판단을 돕고 중요한 건 사람에게 넘겨요 (장면 그림 AI 이미지 생성, 말풍선 글자 직접 넣음)

📌 30초 요약① 코드 고친 신청서를 AI가 검사하고 고치고 통과 판단까지 도와요
② 무엇을 AI가 통과시킬지는 팀이 쓴 규칙표가 정해요
③ 팀·엔터프라이즈 요금제, 깃허브에서 써요(두 기능은 아직 시험판)
2026년 11월 25일 기준 · 앤트로픽 공식 글 확인

1. 클로드 십이 뭐예요?

궁금이코드에도 숙제 검사 같은 게 있어요?
AI 로봇있어요! 코드를 고치면 "이거 합쳐 주세요" 하는 신청서를 내고, 다른 사람이 검사해서 통과시켜야 진짜 프로그램에 들어가요.

이 신청서를 개발자들은 풀 리퀘스트(PR)라고 불러요. 클로드 십은 이 신청서를 맡는 AI 일꾼 셋을 묶은 거예요.

일꾼하는 일
코드 리뷰신청서를 꼼꼼히 읽고 문제를 찾아 적어요
PR 스튜어드(시험판)실패한 자동 시험·지적받은 곳을 고치고, 고친 내용과 되돌리는 법을 메모해요
클로드 어프루벌(시험판)팀이 쓴 규칙표대로 통과시킬지, 사람에게 넘길지 정해요

개발자는 클로드 코드에서 /ship 한 줄로 이 과정을 시작할 수도 있어요.

2. 왜 만들었어요?

궁금이그냥 사람이 검사하면 안 돼요?
AI 로봇할 수는 있는데요, 제가 쓰는 속도를 검사가 못 따라와요. 4컷 만화 2번 칸처럼요.

앤트로픽은 공식 글에서 “클로드 코드 팀에서는 클로드가 코드 대부분을 쓰고, 신청서를 낸 뒤의 일도 그만큼 빨리 움직이길 바랐다”고 밝혔어요. 쓰는 일은 AI가 빨라졌는데, 검사·수정·허락은 여전히 사람 손을 기다렸다는 거예요.

앤트로픽은 자기 팀에서 클로드의 검사를 여러 단계 중 하나로 쓴 뒤, 6월부터 9월 사이 합쳐진 신청서가 두 배 넘게 늘고 나중에 되돌린 비율은 40% 넘게 줄었다고 소개했어요. 다만 이건 앤트로픽 한 팀의 숫자예요.

3. 무엇을 AI가 통과시킬지는 누가 정해요?

궁금이AI가 아무거나 다 통과시키면 어떡해요?
AI 로봇그래서 규칙표가 있어요. 팀이 "쉬운 건 통과, 이런 건 꼭 사람이 봐"라고 적어 두면 저는 그대로 따라요.

규칙표는 팀이 저장소 안에 파일로 쓰고, 보통 말(자연어)로 조건을 적을 수 있어요. 앤트로픽은 처음엔 지켜보기 모드로 켜서, AI가 통과시켰을 신청서를 사람이 확인하며 믿음을 쌓으라고 권했어요. 관리자는 저장소마다 검사 깊이(빠르게·보통·깊게)와 한 달 쓸 돈의 상한도 정해요.

4. 조심할 점은 없어요?

⚠️ 알아 둘 점① 앤트로픽도 '클로드 십은 AI라서 버그나 보안 빈틈을 놓칠 수 있다'고 적었어요.
② 위 숫자는 앤트로픽이 자기 팀에서 잰 거고, 클로드 검사는 여러 단계 중 하나였어요.
③ PR 스튜어드와 클로드 어프루벌은 아직 시험판이에요.
④ 쓴 만큼 돈이 나가요. 지켜보기 모드에서도 클로드 검사를 부르면 요금이 붙어요.

또 기록을 남기지 않는 설정(제로 데이터 보존)이나 의료 정보용 설정(HIPAA)을 쓰는 회사는 아직 쓸 수 없어요.

5. 나는 뭘 하면 돼요?

  1. 개발을 안 한다면 '흐름'만 알아 두기앱이 고쳐지는 과정에 AI 검사가 점점 더 들어가요. 업데이트 소식에 'AI 검사'라는 말이 보이면 이 이야기예요.
  2. 회사에서 쓴다면 한 저장소부터앤트로픽도 저장소 하나, 지켜보기 모드, 한 달 돈 상한부터 시작하라고 권했어요.
  3. 중요한 변경은 사람이 보도록 규칙에 적기돈·개인 정보·로그인처럼 되돌리기 어려운 곳은 사람이 꼭 보게 해요.
✅ 한눈에 정리· 클로드 십은 코드 신청서를 검사·수정·통과 판단하는 AI 일꾼 셋이에요
· AI가 무엇을 통과시킬지는 팀이 쓴 규칙표가 정해요
· 팀·엔터프라이즈 요금제, 깃허브에서 쓰고 두 기능은 시험판이에요
· AI도 놓칠 수 있으니 중요한 변경은 사람이 확인해요

오늘의 큰 흐름: AI가 ‘코드를 쓰는 도우미’에서 ‘검사하고 허락까지 돕는 동료’로 넓어지고 있어요. 지난 글 클로드 오토 모드처럼, 이번에도 핵심은 무엇을 사람에게 남길지예요.
